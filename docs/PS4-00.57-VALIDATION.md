# PS4 test 00.57: exact RSP reciprocal normalization

The validated streaming-first Vulkan initialization fix is saved locally in
commit 14aa467 (00.56). Army Men recovered from the LLE fallback, but it still
has effect-heavy drops; Conker's intro also remains below full speed in places.
This diagnostic targets arithmetic used by both games' geometry processing.

## Change

Three normalization loops in the RSP reciprocal, double-precision reciprocal,
and reciprocal-square-root models repeatedly shift a nonzero unsigned input
until its leading bit reaches bit 31. GCC/Clang now use count-leading-zeros
and one shift. The zero guard, divide ROM, sign handling, exceptional inputs,
rounding and subsequent arithmetic remain identical. Other compilers retain
the original loop. The PS4 object contains the target's LZCNT instruction.

No GPU scratch budget, batching policy, geometry cache, texture resolution,
particle effects or synchronization changes are included. The 00.54 candidates
remain excluded. A separate direct triangle conversion experiment was rejected
because its local timing benefit was inconsistent despite correct commands.

The fresh build path also applies the existing cheat parser patch, matching
the incremental build path and avoiding a parser difference on future rebuilds.

## Evidence and limits

- Differential arithmetic test: 4,263,424 exact outputs across all signed
  16-bit values, 32-bit signed/power-of-two boundaries and a million random
  inputs, covering reciprocal32, reciprocal32_dp, reciprocal16 and rsq32.
  The test passes against the actual patched PS4 source as well as the native
  test copy. The patch applies repeatedly without changing the generated file.
- Army Men: new user-saved slot 0 retrieved privately (SHA256
  a24753b38118f087177121a9ba561c01a124acb4e52beecae2d55bf69dba1ae8).
  Sixteen Vulkan game captures match the original-loop reference exactly.
  Both cold runs report 30 streaming slices with zero LLE fallbacks and no
  ASan memory error or Vulkan validation error.
- Conker: native replay configured for 600 frames, including the saved intro window,
  generated the same 57,477,832 command bytes after restoring the state.
  Aggregate hash is 690e6ef87ef81331 in both runs. No ASan memory error.
- Isolated optimized host benchmark: three million reciprocal16 calls took
  31.6–34.4 ms with the loop and 9.15–9.29 ms with CLZ over four interleaved
  rounds. This is a function benchmark, not PS4 FPS or whole-emulator speedup.
- Historical signed-shift/overflow UBSan warnings in upstream geometry remain;
  they are not claimed fixed. The unchanged software rasterizer object was
  reused for native command testing after verifying all 33 source/header
  dependencies; the modified arithmetic and Vulkan code were built separately.
- PS4 ELF/OELF, deferred constructor, 28 package checks, payload extraction,
  icon and SFO validation pass. Explicit frame capture remains available but
  must be off during frame-rate comparison; GPU timestamps remain disabled.

launch Army Men first at 2x, restore slot 0, then reproduce the effects and
stutters. Compare Conker's intro at the same resolution. Evaluate sustained
minima, duration and frequency of drops, plus audio and graphics. Local exact
results and function timing do not establish that these drops are resolved.
