# PS4 test 00.55: restore the validated geometry and batching policy

Army Men regressed badly with 00.54 and Conker did not improve. This diagnostic
restores the committed 00.53 geometry and tile admission policy. It removes the
projection cache, point-light candidate and tile preflight from the active
builders. A fresh core directory avoids stale objects or experimental headers.
The Mario Kart depth fix and Excitebike dispatch correction remain included.

Coarse HLE task timing remains for diagnosis and now includes streaming slices,
which Army Men uses. It measures wall time including RDP submission/waits, not
GPU execution alone. Two clock calls occur per task or streaming slice; no
per-vertex or per-triangle clocks are added. The number of slices is reported
so the sampling overhead and work distribution can be assessed.

This is a recovery and diagnostic build, not an FPS improvement claim.
Hardware comparison is required: Army Men's first mission at 2x, including
slot 0 and effects, then Conker's intro. Compare sustained minima, their
duration, audio and graphics against preserved 00.53. Explicit framebuffer
capture must remain off during performance measurement.

Private evidence and transfer records: `build/regression-00.54/`. Do not publish
states, ROMs or captures. No public version bump or GitHub publication.

Follow-up: 00.55 did not recover Army Men. See `PS4-00.56-VALIDATION.md` for
the reproduced streaming-first backend initialization defect. This evidence
supersedes any attribution of the 15 FPS behavior solely to the 00.54 candidates.
