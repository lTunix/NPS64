## Mario Tennis

Fully visible triangles can be sent directly to the existing command encoder.
The old path copied their vertices into a temporary polygon, copied them again
into a fan triangle, then converted them to encoder inputs. The direct path
retains the original ordering and encoder, and preserves the original clipper
for boundary triangles, rejection microcodes and special fan models.

Native differential runs alternate the measurement order between original and
optimized implementations and compare every returned command word:

| Sample | Triangles checked | Mismatches | Original routine | Optimized routine |
| --- | ---: | ---: | ---: | ---: |
| Mario Tennis VC | 497,234 | 0 | 324.078 ms | 281.585 ms |
| Mario Kart PAL | 657,168 | 0 | 1,380.231 ms | 1,089.267 ms |

These are aggregate CPU routine timings under native sanitizer instrumentation,
not PS4 frame rates or an estimate of the overall FPS improvement. Physical
validation must examine the duration and frequency of Tennis's drops at 2x.
The supplied Tennis edition is PAL and console logs report a target of 50.01 VI/s.
GPU shaders, FullSync ordering, internal resolution and audio are unchanged.

## Mario Kart / Choco Mountain

The user's PAL image contains F3DEX and F3DLX 0.95 banners. That revision retains
40-byte vertex offsets and an exclusive end in CULLDL. Later F3DEX uses doubled
indices with an inclusive end. The previous decoder instead read the start
from the wrong command bits and truncated the end to eight bits. It could test
unrelated cached vertices and execute display-list tails that should be culled.

The new decoder distinguishes the formats by microcode revision, validates
bounds and retains the existing clip predicate. Tests cover the real eight-
vertex command encoding, nonzero starts, visible/culled tails, modern format,
malformed ranges and bounded banner detection. A native core integration
fixture executes the actual F3D walker for these cases.

The native Mario Kart run above did not execute CULLDL. This is a verified
command-decoding correction, but **the long-session flicker has not been
reproduced or proven fixed**. The user reports a fresh Choco Mountain session
can look normal and start flickering after extended play, including at native
resolution. Test a long session on PS4; if it recurs, save a state before
restarting and compare whether reloading preserves the fault. That distinction
helps separate guest graphics state from transient renderer resource state.
