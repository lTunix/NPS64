# PS4 test 00.56: initialize Vulkan HLE before streaming tasks

Army Men still ran at approximately 14–16 FPS after restoring 00.53 geometry
and RDP batching in 00.55. Those rollbacks did not fix the startup defect.

The Vulkan emitter installed its memory and submission callbacks only inside
`parallel_hle_process_dlist()`. Streaming tasks call `angrylion_streaming_dlist()`
directly. When Army Men was the first game in a fresh process, the backend could
remain null and every streaming task returned -1, causing the RSP to execute
its slower LLE fallback. Opening a game using ProcessDList first could hide
the defect by installing the callbacks. This makes game order material when
comparing performance; source rollback alone was insufficient.

The fix installs the existing Vulkan callbacks at `parallelInitiateGFX()` and
again at `parallelRomOpen()`. It does not force unsupported microcode into HLE
or suppress legitimate fallback checks. The existing task interpreter, FIFO,
FullSync and rendering policy remain. The rejected 00.54 optimization candidates
remain outside the active build.

## Validation

- A regression test using the actual parallel.cpp and parallel_hle.cpp failed
  before the fix: no backend was registered after a cold graphics connect.
  After the fix it passes cold connect, ROM reopen/rebind, memory callbacks,
  and FIFO/register redirect, without invoking ProcessDList to prime the state.
- A separate cold native Vulkan Army Men run reproduced five streaming calls
  and five LLE fallbacks before the fix. This diagnoses route selection, not
  PS4 frame rate. After the fix, a cold Vulkan run completed 20 streaming
  slices with zero LLE fallbacks and no ASan or Vulkan validation errors.
- Coarse HLE diagnostics now report `stream_fallbacks` as well as task/slice
  time. In the failing PS4 00.55 run, approximately 11 streaming calls per
  second consumed only 0.003–0.006 ms/VI inside the HLE entry while total core
  time exceeded 60 ms/VI, consistent with immediately returning to LLE.
- PS4 ELF/OELF, deferred constructor, 28 package validation checks, payload
  extraction, icon and SFO checks pass. No GPU timestamps are enabled.
