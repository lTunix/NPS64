# Local test 00.40: 1080 Snowboarding startup

Public version remains 00.73. This is an isolated local test, not a release.

## Failure and correction

The user's Japan/USA cartridge image is recognized by the existing ROM database
as MD5 `FA27089C425DBAB99F19245C5C997613`, CRC `1FBAF161 2C1C54F1`.
PS4 logs show successful loading, CIC X103 and repeated 1x1 blank scanout,
without a crash in the 00.39 fatal log.

The same image reproduced the blank output under native Ari64. A longer cached
interpreter run reached visible output at VI 95. Debugging Ari64 found that IPL3's
store of `0x17d7` to RDRAM `0x310` was being interpreted as a one-byte repeat,
leaving zero. The game checks this marker and enters its error path when absent.

Ari64 can abandon an MI interpreter window at a branch, retaining the old init
mode bit. Its later unrelated CLEAR_DP write inadvertently restarted a window
and applied that stale mode to the IPL3 marker store. The fix only starts a new
window for explicit SET_INIT or SET_EBUS writes. Existing delay-slot and exception
guards remain. The ROM, its security check, save identity, GPU renderer and audio
are unchanged. The fix is applied by `scripts/patch_jit_mi_window.py` to native
and PS4 builds.

## Validation

- The regression fixture executes the actual core MI store handler. It fails
  against the original handler and passes against the patched PS4 source.
- It covers stale modes with CLEAR_DP, explicit init/EBUS requests, clears,
  address aliases, delay slots and an existing pending exception.
- The native Ari64/Vulkan 2x run reaches visible 1080 output at VI 96. The VI 300
  diagnostic image shows the opening sponsor screen. The session ends cleanly.
- Native startup checks also cover Mario Tennis VC and Super Smash Bros.; logs
  and results are in `build/corrections-00.74/mi-window-regression.json`.
- The generic short GPU trace script did not pass its requirement for more than
  ten readback timing intervals during the 20-second 1080 run. The startup
  result is separate from that broader trace check and is not a PS4 performance
  measurement.
- PS4 ELF/BSS mapping, GPU boot and 28 package checks pass for the local PKG.

## Physical feedback

The user confirmed on PS4 that cover loading and 1080 startup work in 00.40.
Extended gameplay/audio measurements were not supplied.

## Original physical check

Install `NPS64-Vulkan-Game-Test-00.40.pkg` from `/data/pkg`. Launch 1080, allow the
opening screens to complete and test the menu and a race, preferably at both
native and 2x resolution. Confirm controller input, audio and return to the
library. Read fresh console logs before considering the correction validated.

The independent cover-loading/menu fixes from 00.39 are retained. Mario Tennis
2x optimization and Choco Mountain texture popping/flicker remain separate
