# PS4 test 00.54: Conker and Army Men optimization candidates

This diagnostic follows the locally committed 00.53. Excitebike startup and
Mario Kart's validated depth correction remain included. This is not a public
release or a claim that either remaining frame-rate problem is resolved.

## Changes

- RDP batching reserves the incoming primitive's existing conservative tile
  bound before appending it. This replaces the previous full-screen headroom
  while retaining the allocated scratch capacity, primitive order, noise seed,
  synchronization, resource limits, effects and native/2x resolution.
- Conker's point-light attenuation produces the same integer result with a
  zero-result shortcut or 32-bit division when its operands permit it.
- Conker alone can reuse exact post-matrix projections in a bounded 256-entry
  CPU cache. Full viewport and RSP profile changes invalidate entries; lighting,
  texture coordinates and culling remain computed normally. Other microcodes
  and RS paths bypass the cache.
- Coarse one-shot HLE task timing distinguishes graphics-task wall time from
  the remaining core work. Tasks include their RDP waits; this is not an exact
  measure of GPU execution time. There are no per-vertex timestamp calls.

All patches operate on build copies; vendor sources remain untouched.

## Local evidence and limits

- Point-light oracle: 1,524,880 exact cases including real byte-valued lights,
  saturation, nonpositive distances and wide fallback values.
- Projection oracle: 32,000 vertices covering eligibility bypass, collisions,
  viewport/profile changes, scratch registers, signed W and generation wrap.
  A separate real Conker replay matched 326,638 vertex-load calls against the
  retained original implementation. Historical signed-shift UB warnings in
  upstream arithmetic remain; these are not reported as fixed.
- Army Men normal replay: 16 captured game frames matched the reference.
  That scene did not hit the shading scratch limit.
- A separate test-only conservative capacity stress replay exercised the limit:
  all eight captured game frames matched exactly, with capacity-related flushes
  reduced from 872 to 449 and total batches from 887 to 467. Explicit capacity
  checks did not abort, and no AddressSanitizer or Vulkan validation errors were
  reported. This artificially stresses admission accounting; it is not a PS4
  explosion benchmark or a measured FPS improvement.
- The test-only stress code is absent from the PS4 ELF.
- The projection cache has no clear speed benefit in the optimized native-host
  comparison. Its effect on PS4's CPU must be measured before accepting it as
  a performance improvement. It is limited to Conker for this comparison.
- PS4 ELF/OELF, deferred constructor, 28 package validation checks, payload
  extraction, icon and SFO checks pass. GPU timestamps are disabled; explicit
  diagnostic captures remain available and must stay off during FPS comparison.

Private states, captures, logs, manifest and transfer record are under
`build/optimization-00.54/`. They must not be published.

## Hardware comparison required

Install `/data/pkg/NPS64-Vulkan-Game-Test-00.54.pkg`. Compare Conker's intro
at 2x and Army Men's first mission using slot 0, especially explosions and
multiple effects. Report sustained minimum FPS, how long drops last, audio
continuity and visible defects. Compare against preserved 00.53, which reached
42.96 FPS in Conker and approximately 48–50 FPS in Army Men. A better average
alone does not establish that the stutters are corrected.

Do not publish or promote this diagnostic until hardware validation and the
user's authorization.


## Hardware outcome: rejected

The user reported Army Men limited to approximately 15 FPS and no improvement
in Conker (approximately 44 FPS). Retrieved 00.54 logs confirm Army Men intervals
at 10.74–16.95 FPS, with core wall time reaching 102.268 ms while recorded RDP
list time is approximately 4–6 ms. The two Army launches contain 18/20 and 15/32
post-startup samples below 20 FPS. Conker reaches 44.67 FPS in the intro.
Correct local pixels and fewer artificial stress batches did not establish
hardware performance. These candidates are rejected for delivery/publication.

00.55 restores the 00.53 geometry and tile admission policy using a clean core
build. The experimental cache/light/tile patches and their tests were moved
into the ignored private regression directory for investigation; they are not
part of the active builders. The exact responsible candidate has not been
isolated on PS4, so the logs do not justify assigning the regression exclusively
to either CPU projection or GPU batching. HLE diagnostics now also cover the
streaming service used by Army Men, which bypassed the original timer.

Follow-up: 00.55 did not recover Army Men. See `PS4-00.56-VALIDATION.md` for
the reproduced streaming-first backend initialization defect. This evidence
supersedes any attribution of the 15 FPS behavior solely to the 00.54 candidates.
