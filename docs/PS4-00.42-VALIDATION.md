# Local test 00.42: shader compilation demand

## Physical result from 00.41

The user reported Mario Tennis at about 44 FPS and then about 20 FPS, especially
in replays. In the physical 00.41 log, one interval reports 21.04 VI/s against a
50.01 target. FullSync waits account for 38.462 ms per VI on average in that
interval; the maximum RDP time reaches 115.508 ms. The prior CPU triangle-copy
optimization is insufficient to resolve this case.

187 distinct specialized shader requests were observed in the analyzed trace.
A request/compilation join using the surrounding cadence timestamps identifies
up to about 8.1 seconds waiting to complete and a peak of 30 pending requests.
These are approximate queue ages from one-second log anchors, not precise GPU
execution timestamps. The change below targets that delay; it does not prove
that all replay slowdown is due to shader compilation.

## Change

Only the independent shader-compilation worker opts into a demand priority.
The renderer updates a queued shader's demand sequence when it needs that
shader again. The worker reconsiders current demand and new arrivals after
each compile rather than finishing an old FIFO batch first. Shared atomic
demand tokens retain safe ownership while render and compiler threads overlap.

Every normal command worker continues using the unchanged FIFO policy. Vulkan
shader contents, general fallback, resource guards, 2x resolution, FullSync
ordering and audio remain unchanged. New logs include exact per-job shader
queue wait time. Less recently used requests can wait longer; shutdown still
drains every accepted job.

## Checks

- ASan/UBSan worker fixture: 50 repetitions each of FIFO isolation, promotion
  during an active batch, new arrivals, waiter notifications and shutdown drain.
- Native Tennis/Vulkan functional run with validation enabled: visible output,
  all 16 unique queued jobs compiled/drained, no Vulkan validation errors or
  ASan memory errors. Existing unrelated core UBSan diagnostics are not claimed
  fixed. This short run is not a replay performance benchmark on PS4.
- PS4 ELF/BSS mapping, GPU boot and 28 package checks pass.
- Package: `/data/pkg/NPS64-Vulkan-Game-Test-00.42.pkg`; verify the FTP copy by
  retrieving and hashing it before renaming the `.upload` file. Transfer result
  is recorded in `build/corrections-00.74/upload-00.42.json` when complete.
