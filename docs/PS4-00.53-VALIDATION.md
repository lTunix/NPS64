# PS4 test 00.53: remaining-game corrections

Status: user confirmed Excitebike now runs correctly on PS4. Conker and Army Men performance remains unresolved.
No commit, push or public release.

## Changes

1. **Wave Race 64 cover:** normalize the catalog subtitle "Kawasaki Jet Ski"
   to the short ROM name. Region matching remains intact. The USA and Europe
   match tests pass, and the actual USA catalog PNG was downloaded and decoded.
2. **Excitebike 64:** its first graphics task identifies itself as
   `F3DLX.Rej xbus 2.08`. The family classifier excluded `fifo` GBI 2 builds
   but accepted `xbus` as GBI 1, decoding its display lists incorrectly.
   Exclude both GBI 2 transport markers from GBI 1 dispatch. Do not mask the
   invalid texture warnings or skip rendering as a workaround.
3. **CPU geometry:** compute exact RSP screen coordinates first. When valid,
   skip the three fallback perspective divides whose results would have been
   overwritten. Preserve raw W, all output fields and the original fallback.
   This applies to eligible geometry in Conker, Army Men and other games;
   it does not reduce resolution or alter N64 timing.
4. **Conker CPU stability:** ASan exposed `branch_unneeded_reg[-1]` when the
   dynarec compiles a standalone page-spanning delay-slot entry. Keep all guest
   registers conservatively live for this entry, except $zero, and guard the
   preceding-instruction scheduling lookup. Ordinary in-block delay slots keep
   their existing masks. This corrects memory access, not a claimed FPS gain.

All patches operate on build copies; vendor sources remain untouched. The
hardware-validated Mario Kart 0.95 fix remains included.

## Evidence and limits

- Cover matcher and asynchronous cover-worker tests pass under ASan/UBSan.
- GBI family tests cover 0.95/1.21, line microcode, `fifo`, `xbus` and bounded
  input. Existing 0.95 perspective dispatch tests still pass.
- Projection oracle: 300,000 exact output comparisons against the retained
  original function, including standard/RS/fallback models, positive/negative/
  zero W and rounding profiles. No ASan memory error. Historical arithmetic UB
  warnings in the reference/fallback remain and are not claimed fixed here.
- Isolated native projection benchmark at `-O3 -march=btver2`: reference
  14.877–15.283 ms versus 13.131–13.248 ms for 400,000 calls, approximately
  12% less time in this function. These are **not PS4 game FPS measurements**.
- Excitebike: reproduced the invalid RDP stream before the dispatch correction.
  Corrected software run completed 3,981 presentations and reached the course
  selection screen with a rendered rider. Vulkan at 2× advanced beyond the
  previous failure without the invalid texture stream or validation errors;
  its 100-second diagnostic run ended at the external timeout, not a crash.
  A complete race on PS4 is still pending.
- Conker: the original ASan run stopped at the dynarec underflow. After the
  boundary fix, 3,599 presentations of its intro completed without an ASan
  memory error. This does not establish its PS4 frame rate.
- Army Men: a 2,999-presentation smoke test completed without an ASan memory
  error but remained at its Controller Pak warning. It is not validation of
  the outdoor first-mission workload. The user identified that workload for
  the console comparison; Conker's comparison scene is the intro.
- ELF/OELF checks, 28 package checks, extraction, SFO and icon checks pass.

Private logs, images, benchmark and upload record are under
`build/remaining-games-00.52/` and `build/remaining-games-00.53/`.

## Hardware feedback and remaining work

The user confirmed that Excitebike runs correctly on PS4. Conker still falls
to 42.96 FPS, with six consecutive approximately one-second samples below
50 FPS during the intro. The worst interval reports core 23.043 ms/VI,
RDP 2.867 ms and VI 1.199 ms; CPU emulation/HLE needs finer profiling.
Army Men still falls to approximately 48–50 FPS with explosions or effects.
One 50.38 FPS interval reports RDP 7.126 ms (FullSync 6.949 ms), so its effect
workload also needs rendering/synchronization analysis. These are distinct
remaining bottlenecks; the projection-function benchmark did not establish
that either game's frame-rate issue was resolved. Review logs are preserved
privately under `build/conker-00.53-review/`.
